## Sobre mim

Sou desenvolvedor fullstack, com 3 anos de experiência construindo aplicações web do front-end ao deploy. Trabalhei na **Swiftsoft** (Curitiba) em sistemas com React, TypeScript, Node.js, PostgreSQL e Redis rodando em Docker, e criei uma extensão de Chrome que transmite legendas do Google Meet em tempo real por WebSocket.

Também tenho experiência de bancada como técnico em informática e em reparo de iPhones, o que me dá uma visão completa, do hardware ao software.

## Projetos em destaque

### 🛠️ [AssistPro OS](https://github.com/Emanuel565/assistpro-os)
Sistema de gestão para assistências técnicas: ordens de serviço em Kanban, estoque por IMEI e número de série, PDV, financeiro, chat interno por WebSocket e consulta do cliente por QR Code. Roda offline no Windows (Electron + SQLite) ou na nuvem (Docker + PostgreSQL + Redis).
**Stack:** React 19 · Node.js · Express · Prisma · Docker
[🌐 Ver demo](https://emanuel565.github.io/assistpro-os/)

### 🎬 [Limbo AI](https://github.com/Emanuel565/limbo-ai)
Plataforma de cortes verticais (9:16) para TikTok, Reels e Shorts: detecta jogadas com visão computacional, edita com FFmpeg acelerado por GPU, gera títulos com IA local e agenda publicações.
**Stack:** Next.js 15 · React 19 · TypeScript · Python · OpenCV · FFmpeg · Ollama

### 🎙️ [Meet Transcriber Pro](https://github.com/Emanuel565/meet-extension)
Extensão Chrome (Manifest V3) que captura as legendas do Google Meet e envia em tempo real por WebSocket, com fila de eventos, reconexão automática e consentimento do usuário.
**Stack:** JavaScript · Chrome Extensions · WebSocket

### 💈 [Curitiba Editorial](https://github.com/Emanuel565/curitiba-editorial)
Landing pages editoriais em React para negócios locais de Curitiba, publicadas no GitHub Pages.
**Stack:** React 18 · CSS3 · GitHub Pages
